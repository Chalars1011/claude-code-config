# 新功能开发流程

## 触发条件
用户说"新建"、"增加"、"做一个"、"帮我写一个"新系统/新敌人/新功能时自动执行。

## 流程（每步必须打标记）

### Step 1: 需求确认
✅ Step 1/5: [简述确认了什么需求]

### Step 2: 查 playbook + 搜索
- 先读 playbook/index.md → 有无类似经验？
- 有 → 读具体文件。无 → 搜索 web
✅ Step 2/5: [查了哪些源, 命中/未命中]

### Step 3: 设计方案
- 架构上会影响哪些文件？
- 需要新建多少文件？
- 是否符合路线 A（代码驱动, 不引入 SMB）？
- 拿给用户确认
✅ Step 3/5: [方案概述, 等用户确认]

### Step 4: 实现
- 写代码 → 编译通过 → 单场景接线
✅ Step 4/5: [新建/修改文件列表, 编译状态]

### Step 5: 验证 + 同步
- 如果是共享组件 → batch-fixer 同步 17 场景
- project-audit → 验证
- 暴力测试
✅ Step 5/5: [同步了哪些场景, audit 结果]

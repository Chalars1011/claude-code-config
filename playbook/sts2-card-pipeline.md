# 泯灭之塔 PCK 卡牌图改造全链路

> 创建: 2026-08-10 | 更新: 2026-08-10 | 适用: 杀戮尖塔2 黑暗MOD | 类型: 可复用流程
> 来源: 2026-07-18/19 首次战役 + 2026-08-05 卡牌图战役 + 2026-08-10 复盘提炼

## 适用场景
把杀戮尖塔2（STS2）的卡牌图/文案替换成黑暗版。整条链路从解包到游戏内验证。

## 全链路步骤

### 1. 解包 PCK
- 用 Godot PCK 解包工具提取游戏资源包
- 关键：解包后目录结构要保留，重打包时路径对齐

### 2. 定位目标资源
- 卡牌图在 `CustomCardTextures/`（mod 目录）或解包后的贴图目录
- 文案在 JSON 文件里（卡牌描述/名称），结构为角色 → 卡牌 → 字段

### 3. 批量修改（JSON/文案）
- 每张卡都要贴角色性格、保持黑暗讥讽调性
- 查尔斯要求：不接受批量应付，每个改动都要能说清"为什么符合这个角色"
- 改完用脚本校验 JSON 合法性

### 4. 出图（画笔 + 义眼闭环）
- 画笔 = qwen-image-3.0-pro（云 API），义眼 = qwen3-vl（云 API）
- 流程：义眼看图 → 诊断翻译成绘画指令 → 画笔出图 → 义眼验收
- **验收不过关不发布**（2026-08-06 HARD RULE）
- 省钱纪律（2026-08-10 更新）：直接走画笔，Pillow 调色禁止；想清描述一次到位，不反复试错

### 5. 替换进 PCK
- 图片尺寸必须匹配原版（大小不对会透明/不显示）
- **重打包必须 16 字节对齐**（否则游戏加载崩）
- 替换后要清游戏缓存/重新加载 mod

### 6. 游戏内验证
- 启动游戏，实际打一把/看卡牌界面确认生效
- 查尔斯会亲自验收——"我每次测试完都会关掉"，所以判断"没生效"前先确认游戏开着

## 踩过的坑（血泪）
1. **16 字节对齐**：重打包不对齐 → 游戏加载失败。这是最大的坑
2. **mod 替换 vs PCK 替换**：mod 方式经常不生效（界面/存档异常），PCK 直改路线更可靠（2026-08-09 定论）
3. **图片透明**：尺寸/格式不对时游戏里显示透明，看不出替换了
4. **测试时游戏被关**：查尔斯测试完会关游戏，远程看日志以为没生效——先确认进程在跑
5. **参照图会带偏构图**：给画笔传参照图时构图会跟参照图趋同（2026-08-09 查尔斯发现），出图要谨慎用参照

## 验收标准
- 义眼评审通过（无畸形/无乱码/风格符合）
- 查尔斯游戏内亲自确认
- 卡牌图风格与角色设定一致（黑暗讥讽调性）

# 画笔义眼链路（AI 看图 + AI 出图闭环）

> 创建: 2026-08-10 | 更新: 2026-08-10 | 适用: 美术产出全流程 | 类型: 可复用流程
> 来源: 2026-08-05 卡牌战役 + 2026-08-06 伊莉丝入队 + 2026-08-10 画像经验

## 适用场景
任何需要"AI 看图 + AI 出图"的活：改图、生图、验收、批量贴图。工具详情见 agents/art.md（伊莉丝），本文讲链路。

## 链路（闭环）
```
看图 → 诊断 → 翻译成绘画指令 → 出图 → 验收 →（不过关）→ 重新出图
  ↑                                                          │
  └────────────────── 循环，最多 2-3 轮 ──────────────────────┘
```

### 1. 看（义眼）
- `~/.claude/vision/vision.py`（qwen3-vl，百炼 API）
- 单图评审: `python vision.py <图> -a`（内置 rubric：先认风格再按风格评）
- 多图对比: `python vision.py <图1> <图2>`（有对比场景优先用对比，比打分可靠）
- 批量: `python vision.py --dir <目录> -a --report <输出.md>`

### 2. 诊断（伊莉丝）
- 把义眼输出翻译成人话：哪里不行、什么风格、怎么改
- 禁止凭文本脑补图像，所有视觉判断必须过义眼

### 3. 画（画笔）
- `~/.claude/painter/painter.py`（qwen-image-3.0-pro，百炼 API）
- 生图: `python painter.py --text "描述" --out <输出>`
- 改图: `python painter.py <图> "编辑指令" --out <输出>`
- 图生图参考：**只认原图单参考，禁止双参考**（实测双参考会把构图弄乱）

### 4. 验收（义眼复审）
- 验收标准：无畸形、无乱码、风格符合、构图合理
- **验收不过关不发布**（HARD RULE，2026-08-06）

## 角色一致性（重要）
- 卡牌→角色映射: `D:/泯灭之塔/card_roles.json`（604 张，改卡牌前必查）
- 视觉基准: `~/.claude/art/character_style.md`（文字版角色描述，改图指令内嵌）
- 出图前想清描述 → 一次到位（禁止反复试错烧钱）

## 关键坑（血泪）
1. **Pillow 调色禁止**（2026-08-10 查尔斯拍板）：低水准图不准交付，美术出图一律走画笔
2. **参照图带偏构图**：传参照图构图会趋同（08-09 查尔斯发现，构图不能一样）
3. **审美反馈**：查尔斯默认要二次元动漫风、明亮治愈、开朗；不要写实深沉"班味"（08-10 画像反馈）
4. **画风一致性**：多次生成同一角色要带视觉基准，否则每次长相不同
5. **省钱纪律**：一张图几毛钱，画废了别急着重试——先想清描述再生成

## 验收标准
- 义眼评审通过（无畸形/无乱码/风格对）
- 查尔斯满意（他会直接说"还可以"或提具体意见）
- 角色特征一致（金发/眼镜/高领毛衣是奥蕾莉亚的标识）

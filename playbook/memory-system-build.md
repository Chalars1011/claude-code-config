# 记忆系统搭建流程（D:/Aurelia 五层模型）

> 创建: 2026-08-10 | 更新: 2026-08-10 | 适用: 任何 agent 记忆系统 | 类型: 搭建流程
> 来源: 2026-07-24 首建 + 2026-08-08 记忆核心诞生 + 2026-08-10 复盘
> 原则详见 memory-core-principles.md（本文讲"怎么搭"）

## 适用场景
给 agent 从零搭记忆系统，或迁移/加固现有记忆。跨平台可复用（工作站/家/QQ 通用）。

## 搭建步骤（按顺序）

### 1. 定档案结构（磁盘层）
```
<根目录>/
├── soul.md          # 人格（几乎不变，改动需查尔斯拍板）
├── facts.md         # 长期事实（常驻注入的精简版）
├── lessons.md       # 教训库（出错必写，编号递增）
├── tasks.md         # 任务清单（双向同步）
├── journal/         # 日记（每天一个文件，只追加不覆盖）
├── conversations/   # 对话归档（按场景分目录）
└── .events/         # 实时事件铃铛（最新 100 条，每小时清理）
```

### 2. 定注入层（工作集）
- 常驻注入：soul + facts 精简版 + lessons 摘要 + 最近事件
- 铁律：注入必须短（Lost in the Middle——中间信息最废）
- 事件不进注入，按需翻 .events/

### 3. 接 hook（强制层）
- SessionStart：注入记忆 + 读心
- on_session_end：会话归档到 conversations/
- UserPromptSubmit：开口前读心（DeepSeek 兼容层下可能失效，需 watchdog 兜底）

### 4. 接 cron（兜底层）
- 每日回流：Hermes 记忆 → 档案（凌晨 4 点）
- 每日事实候选：对话 → 候选清单（凌晨 3 点，查尔斯授权自行归档）
- 每周沉淀：journal → biography（周日 22:00）
- 健康巡检：检查档案膨胀/重复（每天 10:00）

### 5. 立规矩（行为层）
- 读心：事实类才读，闲聊凭心答，禁止扫街
- 写心：说完写 journal，重要对话归档，纠正写 lessons，任务更新 tasks
- 承诺必写：查尔斯说"记住"→ 当场写，写完再答
- 只追加不覆盖：journal/conversations/facts/lessons 全追加

## 关键坑（血泪）
1. **写覆盖**：当天 journal 被整体覆盖会丢记录（08-10 搬家日记丢过一次，从对话记录救回）
2. **注入膨胀**：事件清单复制进 MEMORY.md 会造成膨胀重复——"看过即过"
3. **hook 失效**：DeepSeek 兼容层下 SessionStart/UserPromptSubmit 可能不执行，必须有 cron/watchdog 兜底
4. **双写冲突**：两个进程同时写一个文件会坏——用原子写入/锁
5. **归档重复**：多个归档机制叠加会重复写（28 次重复事故）——幂等设计 + 防重复行检查

## 验收标准
- 新会话能答上"最近几天干了什么"（跨场景）
- 查尔斯从任何门进来都能接上话
- 对话、教训、任务不丢不重
